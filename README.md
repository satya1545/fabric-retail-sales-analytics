# Retail Sales Analytics using Microsoft Fabric

## Project Overview

This project demonstrates an end-to-end Retail Sales Analytics solution built using Microsoft Fabric.

## Technologies Used

- Microsoft Fabric
- Lakehouse
- OneLake
- Data Pipeline
- SQL Warehouse
- Power BI
- DAX
- SQL

## Architecture

Bronze → Silver → Gold

## Data Model

Fact Table

Dimension Tables
- DimCustomer
- DimDate
- DimProduct
- DimSalesTerritory

- Total Customers KPI
- Total Products KPI
- Monthly Sales Trend
- Sales by Country
- Top Products
- Sales by Territory
- Year Filter
